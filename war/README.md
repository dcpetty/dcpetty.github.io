# [War](https://dcpetty.github.io/war/)

This tool was written with [PyScript](https://pyscript.net/) &mdash; a way of mixing [Python](https://docs.python.org/3/) with [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) &mdash; for those of us comfortable with things [Pythonic](https://realpython.com/ref/glossary/pythonic/).

This tool is an instantaneous display of the <em>Estimated [Cost](https://costsofwar.watson.brown.edu/) of the MAGA [war-of-choice](https://en.wikipedia.org/wiki/2026_Iran_war) for Israel against Iran know as **Epic Cluster**</em>. 

This tool was written by [ChatGPT](https://chatgpt.com/share/69ee57d6-c768-83ea-a92e-e2bf54c7a19a) with tweaks by me.
